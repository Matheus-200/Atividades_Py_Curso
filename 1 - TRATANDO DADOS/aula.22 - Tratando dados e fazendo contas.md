**calculando a raiz quadrada usando (math)**



import math #importando os calculos matematicos

num = int(input("Escreva um número: ")) 

raiz = math.sqrt(num) #essa função serve para raiz

print("A raiz quadrada de {}, é: {}.".format(num, raiz))



* CASO EU QUEIRA ARRENDONDAR PARA CIMA EU ULTILIZO: math.ceil
* CASO EU QUEIRA SOMENTE O VALOR INTEIRO EU ULTILIZO: math.trunc 



trunc = pega somente o valor inteiro, sem as virgulas.

sqrt = calculando raiz.

ceil = arredonda para cima.
